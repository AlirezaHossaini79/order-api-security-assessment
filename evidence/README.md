# شواهد ارزیابی

فایل‌های JSON شامل زمان UTC، فرمان اجرا و نتیجهٔ هر بررسی هستند. در شواهد HTTP، درخواست و پاسخ با پوشاندن Authorization و اطلاعات اتصال دیتابیس ثبت شده‌اند.

- `before.json`: شش بررسی برای ثبت و بازتولید وضعیت اولیه.
- `after.json`: ۳۵ تست امنیت و عملکرد نسخهٔ اصلاح‌شده.
- `runtime.json`: ده بررسی تنظیمات واقعی کانتینر و مجوزهای DB.
- `clean-security.json`: ۳۵ تست امنیت و عملکرد با volume و رمز تازه.
- `clean-runtime.json`: ده بررسی تنظیمات محیط تازه.
- `clean-run.log`: خروجی زمان‌دار نصب پاک، تست‌ها، بار نمونهٔ ۱۰۰ درخواست و پاک‌سازی منابع موقت همان اجرا.

ابزارهای تولید شواهد در `lab/tests/security_checks.py`، `lab/tools/runtime_checks.py` و `lab/tools/verify_clean.py` قرار دارند. حالت `--expect vulnerable` بازتولید ضعف‌های نسخهٔ اولیه و حالت `--expect fixed` اعتبارسنجی نسخهٔ اصلاح‌شده را بررسی می‌کند.
